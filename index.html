Correlate monitoring inventory
Log AnalyticsNot executed in this review.

Run in the intended workspace(s). Requires supported Container insights streams and DCR association, independently of MDE. Join on normalized resource + computer + normalized FULL container ID, never a prefix. Missing image-side rows remain visible. | where TimeGenerated > ago(2h)

Derive candidate runtime identity (heuristic, not native enrichment)
Defender XDR Advanced HuntingExecuted successfully; 45 returned rows. 3 selected rows retained; not a complete response export. Capture completeness unknown.

Extracts a candidate container ID from an observed containerd parent working-directory path. This is a heuristic, not a native ContainerId field or complete inventory; verify against the runtime's actual container ID and execution time. The path alone can be imitated and does not supply pod, image digest, image CVEs or a security alert. Runtime/layout differences and missing event context can produce no rows. Results are a 200-row sample.

DeviceProcessEvents
| where Timestamp > ago(1d)
| extend HostContext=parse_json(AdditionalFields)
| extend RuntimeWorkingDirectory=tostring(HostContext.InitiatingProcessCurrentWorkingDirectory)
| extend DerivedContainerId=extract(@"/(?:k8s[.]io|moby)/([0-9a-f]{64})/rootfs(?:/|$)", 1, RuntimeWorkingDirectory)
| where isnotempty(DerivedContainerId)
| project Timestamp, DeviceId, DeviceName, FileName, ProcessId,
          DerivedContainerId, RuntimeWorkingDirectory, ProcessCommandLine, ReportId
| order by Timestamp desc
| take 200
